# Lumina SFX v1.5.0 release candidate

An agent can choose who is listening, which sound carries a scene, and where the other sounds sit. Every catalog recipe can be used as an independent spatial emitter. This candidate adds scene capabilities to the existing 2,853 sound bank.

## What to try

- Put a jet in a storm. Switch focus from engine to weather, hold both in focus, or let thunder cover the engine once. The mixer measures the combined backgrounds after distance, filtering and placement. Each authored section gets a steady gain and an eased handoff. Locks preserve authored levels.
- Orbit a source, turn the listener, or send a sound overhead. A headphone WAV uses measured human head responses. Live Web Audio uses the browser's HRTF. Speaker and mono outputs remain available. Recorded UI can stay fixed as the world turns.
- Ask for quieter wind. Stable layer labels preserve the fire's take, event timing and position. Review the dry stems, positioned solos, delivered margins and weakest overlap time before wiring a scene into the game.
- Open and close a hangar door on a running rain loop. The game can supply obstruction; opening the door restores brightness and changes the reflected sound.

## Candidate checks on an Apple silicon Mac

| Check | Observed |
| --- | --- |
| Released masters | All 2,853 default 44.1 kHz PCM masters retained their v1.1 hashes. A point placement was also constructed for every ID and exercised on an excerpt. |
| Engine in a storm | With the same takes, poses and clocks, the engine moved from 5.9 dB below the summed weather to 8.0 dB above at the fifth percentile of active overlap windows. Its delivered mono phone-band margin was 9.3 dB. Reversing the subject gave the rain an 8.0 dB margin. |
| Automated regressions | TypeScript and the complete Node test set passed. Checks include focus locks, shared subjects, order independence, handoffs, intentional silence, replay seeds, HRTF sided arrival, elevation filter differences, cone gain, relative Doppler, spread, mono and reversible obstruction. |
| Live Chrome | One, eight and 32 concurrent sources in each of listener-relative, speaker and HRTF modes. The signal probe found zero intervening silent frames. At 32 HRTF sources scheduling took 4.6 ms and the 95th-percentile animation frame interval was 16.7 ms on this run. |
| First play | The first native HRTF warmup took about 110 ms during preload. With playback scheduled 35 ms ahead, signal reached the worklet in about 41 ms for headphones. Device and driver latency are additional. Preloading the small local pack with a warm HRTF cache took 20 ms cold-file and 7 ms warm-file. |
| Interactive control | A stationary source measured 12.5 dB louder on the left, then 12.5 dB louder on the right after a listener turn, then back on the left after a source move. A separately installed seven-second orbit rendered with 308,700 frames in Chrome. |
| Delivery | The Skills CLI upgraded a project-scoped install from v1.1 using a local Git mirror. Generated TypeScript scenes reproduced their checked WAVs. The speaker install omitted the measurement table; the binaural install included its license and notice. |
| Other engines | Godot, Unity, Unreal and Python asset installs passed. Pygame stereo rotation and live loops ran with its dummy audio driver. Native Godot, Unity and Unreal editor playback and physical-device latency remain unmeasured. |

Three matched A/B files compare focus, a one-line level edit and cockpit/beach viewpoints. Each pair measured within 0.01 LU after linear gain matching. The orbit is a separate headphone performance. A blind listening desk provides a phone-band option. Perceived front/back and height vary with the listener and headphones. Individual recognition still needs human listening.

Run `npm run typecheck`, `npm run test:listening` and `npm run qa:legacy` for repeatable local checks. To repeat the browser test, install a scene pack, set `LUMINA_PLAYWRIGHT` to the local Playwright module and `LUMINA_CHROME` to the browser executable, then run `node qa/browser-listening.mjs /path/to/pack`.
